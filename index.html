02 / Automation Production

Scorecard API

The test rig already knew when the test finished, so I let it request its own analysis. An R Plumber API in Docker that turns two CSVs and a curl request into a scored plot, a graded table, a grate heat map and an interactive report.

→ 83% faster analysis (30 min → 5 min), zero manual data transfer
